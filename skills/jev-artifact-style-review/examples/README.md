# Examples

All examples are synthetic. They are not private client documents, captured Jev outputs or measured quality improvements.

`email_ja_before.md` and `email_ja_after.md` illustrate a meaning-preserving local edit using the supplied context example.
They do not include fabricated Jev scores. The before/after outcome must be measured with an authorized live API run.

`pilot_cases.jsonl` contains 20 Japanese and 10 English boundary cases with intended checks, not validated labels.
Use them to exercise exception handling and collect human reviews before assessing real task accuracy.

No API keys, client documents or original business messages are included.
