# ELI5

## 1. 概要

対象トピックを、1分程度で読み切れる自己完結型のHTML説明ページに変換します。大きな図が説明の主役で、文字は図をつなぐラベルの役割に徹します。

名前は「5歳児向け」ですが、狙いは子ども向けの語彙で話すことではありません。読み手が持っていない前提知識を取り除くことです。実際に5歳児の語彙を目指すと説明が不正確になりがちなので、「そのテーマを一度も聞いたことがない賢い大人」を想定します。これなら平易さと正確さを両立できます。

図が効くのは、読み手がその概念に初めて出会うからです。図は物事の形を一目で示しますが、文字の壁は読み手に頭の中でその形を組み立て直させます。

依頼のなかで聞き手が指定されていれば、その人に合わせて例えと語彙を選びます。上司、顧客、家族、子どもなど、想定読者が変われば適切な例えも変わります。

---

## 2. 利用シーン

- 「ELI5」「簡単に説明して」「図で説明して」「初心者向けに」「素人にもわかるように」と依頼されたとき
- 技術的な内容を、非技術者の上長・顧客・家族に説明する必要があるとき
- ビジュアル説明資料、図解ウォークスルー、初心者が追える1枚ものを求められたとき
- 一度説明したが伝わらず、もっと平易な版を求められたとき
- 「ELI5」という言葉が出てこなくても、前提知識の欠如が理解の障壁になっているとき

**このスキルの対象外**: 厳密な技術仕様書は `technical-spec-writer`、その分野を既に理解している聴衆向けのプレゼン資料は `fujisoft-presentation-creator` を使ってください。アーキテクチャ設計書も対象外です。

---

## 3. 前提条件

- APIキーは不要です
- スクリプトや外部依存はありません。指示のみで構成されたスキルです

---

## 4. クイックスタート

説明してほしいトピックを伝えるだけです。

```
DNSの仕組みをELI5で説明して
```

```
うちの部長にRAGを説明したい。図で説明して。
```

ClaudeがHTMLアーティファクトを1つ生成し、リンクを返します。

---

## 5. 生成物の構成

CSSとSVGをすべてインライン化した、自己完結型のHTMLアーティファクトを1つ生成します。外部スクリプト、外部スタイルシート、外部画像は読み込みません。

| 構成要素 | 内容 |
|:---------|:-----|
| 冒頭 | アイデアを1文で表した見出しを大きく配置 |
| パネル | 数枚の大きなパネル。各パネルに図1点と、1〜2行の短い文 |
| 具体例 | 一般的な定義ではなく、具体例を1つ |
| 締め | 「だから何なのか」を1行で。読み手にとっての意味 |

図はシンプルなSVGの図形、矢印、ラベルで十分です。ここでは正確な技術図より、うまい例えを絵にしたもののほうが機能します。全体の文字量は1分で読み切れる範囲に収め、段落を書きそうになったら図に置き換えます。

出力言語は依頼者が使っている言語に合わせます。指定された聞き手が別の言語を読む場合は、そちらを優先します。
